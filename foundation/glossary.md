# 用語集

**この文書に書くのは「用語をどう表記し、どう定義するか」だけである。**

教材で使う用語の正式表記と定義を管理する。`style-reviewer` はこの表記を基準に揺れを検出する。

## 運用ルール

1. 専門用語を初めて使うときは、教材内で定義してからこの表に登録する。
2. 同一概念に複数の呼び方をしない。「別表記」欄にあるものは使用禁止。
3. 定義は、`audience.md` の前提知識だけで理解できる言葉で書く。
4. 用語を追加・変更した PR では、既存の章への影響を確認する。
