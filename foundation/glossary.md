# 用語集

**この文書に書くのは「用語をどう表記し、どう定義するか」だけである。**

教材で使う用語の正式表記と定義を管理する。`style-reviewer` はこの表記を基準に揺れを検出する。

## 運用ルール

1. 専門用語を初めて使うときは、教材内で定義してからこの表に登録する。
2. 同一概念に複数の呼び方をしない。「別表記」欄にあるものは使用禁止。
3. 定義は、`audience.md` の前提知識だけで理解できる言葉で書く。
4. 用語を追加・変更した PR では、既存の章への影響を確認する。

## 用語

| 用語 | 定義 | 別表記（使用禁止） |
|---|---|---|

| Claude Code | Anthropic が提供する、ターミナルで動作するコーディングエージェント。 | claude code / ClaudeCode |
| コーディングエージェント | 指示を受けて、コードの読み書きとコマンドの実行を自分で繰り返し、タスクを完了まで進めるプログラム。**初出で定義したあとは「エージェント」と省略してよい。** | AIエージェント / AI エージェント / コーディング エージェント |
| コンテキスト | AIモデルが一度の応答を生成する際に参照できる情報の全体。 | 文脈 |
| サブエージェント | 親のエージェントから起動され、独立したコンテキストでタスクを実行するエージェント。 | サブ エージェント / 子エージェント |
| 局面 | ループのなかでエージェントが行う動作の区分。Claude Codeは「コンテキストを集める」「アクションする」「結果を確かめる」の3つを挙げる。 | フェーズ / phase |

| ループ | エージェントが人の指示を受けてから、完了して人に戻るまでの一連の動き。1回のループのなかで、集める・変える・確かめるが繰り返される。 | 一巡 / イテレーション / 反復 |

| チェックポイント | エージェントがファイルを編集する前に保存する、そのファイルの内容。巻き戻しはこの保存内容を書き戻す。 | スナップショット |

（章の執筆に合わせて追加していく）

「コーディングエージェント」を正式表記にしたのは、`audience.md` の前提知識がこの語で書かれており、教材が扱う対象を「AIエージェント」より正確に指すためである。

「ループ」と「局面」を登録したのは、1章の見出しと本文がこの2語を軸に組み立てられており、章をまたいで揺れると読み手が対応づけを見失うためである（1章2節のドラフトのレビューで指摘）。

当初は「一巡」（全体）と「ループ」（繰り返される部分）を分けていたが、区別を本文で説明しなければ通じないことが分かり、「ループ」1語に統一した。公式ドキュメントの `agentic loop` とも対応する。1回分を指すときは「1回のループ」と書く。

「セッション」「権限モード」「チェックポイント」を登録したのは、1章3節のレビューで、いずれも定義なしに使われていたためである。3語とも2章以降でも使う。
