# スタイルガイド

執筆時とレビュー時の両方で参照する。`style-reviewer` と `writing-reviewer` はこの文書を判定基準にする。

ここに書かれたルールは、振り返り（`/retro`）で得られた知見を反映して更新していく。ルールを追加するときは、なぜそのルールが必要になったのか（どの指摘が繰り返されたのか）を1行添える。

---

## 1. パラグラフライティング

段落は教材の最小単位である。段落単位で意味が完結していれば、受講者は拾い読みでも論旨を追える。

1. **1段落1トピック**。ひとつの段落で主張することはひとつに限る。
2. **段落の第1文は要約文（トピックセンテンス）にする**。第1文だけを拾い読みしても、節の論旨が通ること。
3. 第2文以降は、第1文の**根拠・詳細・具体例**のいずれかに限る。新しい主張を持ち込まない。
4. 段落の長さは**3〜6文、200〜400字**を目安にする。超える場合はトピックが複数混ざっている疑いがある。
5. 段落の並び順は、節の主張から演繹される順序にする。時系列や思いつき順に並べない。
6. **見出しの直下には、その見出しの主張を1文で置く**。この1文がスライド化時のリード文になる。

## 2. テクニカルライティング

1. **一文一義**。ひとつの文で述べることはひとつ。80字を超えたら分割を検討する。
2. **主語と述語を近づける**。間に長い修飾節を挟まない。
3. **修飾語は被修飾語の直前に置く**。係り受けが二通りに読めないこと。
4. **曖昧語を使わない**。「など」「適切に」「基本的に」「かなり」「しっかり」は、具体的な語に置き換えるか削除する。
5. **指示語は、直前の名詞が一意に定まるときだけ使う**。「これ」「それ」が段落をまたぐ場合は名詞を繰り返す。
6. **二重否定を使わない**。「〜しないわけではない」は肯定形に直す。
7. **能動態を基本にする**。動作の主体が誰かを明示する。
8. **並列は文法的に揃える**。箇条書きの各項目は同じ品詞・同じ構造にする。
9. **数値と条件は具体的に書く**。「多くの場合」ではなく「3件中2件で」と書けるなら書く。

## 3. 表記

| 項目 | ルール |
|---|---|
| 文体 | ですます調 |
| 英数字 | 半角 |
| 和欧文間のスペース | 入れない（例: `Claude Codeを使う`） |
| 括弧 | 和文中は全角（）、コード・コマンド内は半角 |
| 句読点 | 「、」「。」 |
| 感嘆符・疑問符 | 原則使わない |
| 数字と単位 | 半角、間にスペースを入れない（例: `3件`、`80字`） |
| 箇条書きの文末 | 文になる項目は「。」で終える。体言止めの項目は句点なし。**1つのリスト内で混在させない** |
| 用語 | `glossary.md` の表記に従う。同一概念に複数の呼び方をしない |
| 強調 | `**太字**` のみ使う。傍点・下線・色は使わない |
| コード・コマンド・ファイル名 | バッククォートで囲む |

## 4. 見出しと文書構造

スライド化（Marp / Slidev）を見据えた制約を、執筆時点から守る。変換時の手戻りを防ぐため。

| 見出し | 役割 | 制約 |
|---|---|---|
| H1 | セクションのタイトル | ファイルに1つだけ |
| H2 | **スライド1枚分の主題** | 直下に主張文を1文置く。配下の本文は600字以内を目安にする |
| H3 | H2 内の論点 | 見出しの深さは H3 まで。H4 以下は使わない |

## 5. ツール固有の記述

原則は寿命が長く、ツールの仕様は短い。両者を混ぜると、教材全体が短命になる。

- ツール固有の操作・設定・挙動は、**必ず囲みの中に書く**。

```markdown
> [!NOTE]
> **Claude Code v2.0 時点** — サブエージェントは `.claude/agents/` に配置します。
> 出典: https://example.com/docs （2026-08-22 確認）
```

- 囲みの外は、ツールが変わっても成立する原則の記述に限る。
- ツール固有の記述には**必ず出典 URL と確認日を書く**。同じ内容を `sources/references.md` にも記録する。
- 囲みを含むファイルは、frontmatter に `tool_version` を記載する。

## 6. frontmatter

教材の各 Markdown ファイルの冒頭に置く。

```yaml
---
title: AIに任せる境界
chapter: 1
section: 2
status: draft        # draft | reviewed | fixed
updated: 2026-08-22
sources:             # 参照した一次情報（sources/references.md の ID）
  - REF-003
tool_version:        # ツール固有記述がある場合のみ
  claude_code: "2.0"
---
```

| status | 意味 |
|---|---|
| `draft` | 執筆済み、レビュー未実施 |
| `reviewed` | `/review-doc` 実施済み、指摘が未反映 |
| `fixed` | Critical / High の指摘をすべて反映済み。マージ可能 |

## 7. 禁止事項

- 出典のないツール固有の断定
- 受講者を主語にした決めつけ（「あなたはこう感じるはずです」）
- 根拠を示さない優劣の主張（「〜のほうが優れています」）
- 未定義の専門用語の初出使用（`glossary.md` に登録し、初出時に定義する）
