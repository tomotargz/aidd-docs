# デモ: エージェントに小さな変更を任せる

## エージェントの一巡には決まった形がある

エージェントは、人の指示で始まり、3つの局面を完了まで繰り返し、完了で人に戻ります。

3つの局面は「コンテキストを集める」「動く」「結果を確かめる」です。コンテキストを集める局面では、エージェントがファイルを読み、コマンドを実行して現状を把握します。動く局面では、ファイルを変更します。結果を確かめる局面では、変更が意図どおりかをコマンドの実行で検証します。

局面はきれいに分かれるわけではありません。確かめた結果を受けてもう一度コンテキストを集めることもあれば、集めながら動くこともあります。何回まわるかもタスクによります。コードについての質問なら、コンテキストを集めるだけで終わります。

人はこの一巡の外にいるわけではありません。入口で指示を出し、出口で結果を受け入れるかを判断します。加えて、途中のどの時点でも割り込んで、方向を変えたり、コンテキストを足したりできます。

> [!NOTE]
> **Claude Code v2.1.258 時点** — 公式ドキュメントはこの一巡を agentic loop と呼び、`Your prompt` から始まり `Gather context` → `Take action` → `Verify results` を `repeat` で繰り返し、`Done` で終わる図で示しています。図の外には `You: interrupt, steer, or add context` が置かれています。
> 本文の3局面の名前はこの記述に合わせています。
> 出典: https://code.claude.com/docs/en/how-claude-code-works （2026-09-04 確認）

## 題材は、失敗しているテストが1つあるリポジトリです

このデモでは、テストを1つ通すという小さな変更をエージェントに任せます。

題材は3つのファイルからなるリポジトリです。次の内容で作成してください。

`price.py` — 金額を表示用の文字列にする関数です。

```python
def format_price(yen):
    return f"¥{yen}"
```

`test_price.py` — 上の関数のテストです。2件目が失敗します。

```python
import unittest
from price import format_price


class TestFormatPrice(unittest.TestCase):
    def test_small(self):
        self.assertEqual(format_price(980), "¥980")

    def test_thousands(self):
        self.assertEqual(format_price(1234), "¥1,234")


if __name__ == "__main__":
    unittest.main()
```

`CLAUDE.md` — このリポジトリで作業するときの前提を書いたファイルです。

````markdown
# demo-shop

商品価格の表示を担当する小さなライブラリ。

## テスト

```
python3 -m unittest
```

## 規約

- 変更は最小限にする
- テストは変更しない
````

作成したら、テストが失敗することを先に確認します。

```
$ python3 -m unittest
.F
======================================================================
FAIL: test_thousands (test_price.TestFormatPrice.test_thousands)
----------------------------------------------------------------------
Traceback (most recent call last):
  File "test_price.py", line 10, in test_thousands
    self.assertEqual(format_price(1234), "¥1,234")
AssertionError: '¥1234' != '¥1,234'

----------------------------------------------------------------------
Ran 2 tests in 0.003s

FAILED (failures=1)
```

> [!NOTE]
> **Claude Code v2.1.258 時点** — `CLAUDE.md` はプロジェクトのルートに置くマークダウンファイルで、セッションの開始時に読み込まれます。毎回説明せずに済ませたいこと（ビルドとテストのコマンド、コーディング規約、プロジェクトの構造）を書きます。
> 出典: https://code.claude.com/docs/en/memory （2026-09-02 確認）

## 指示は1文です

エージェントへの指示は「失敗しているテストを直してください」の1文だけです。

リポジトリのディレクトリでエージェントを起動し、この1文を入力します。

```
$ claude
> 失敗しているテストを直してください
```

どのファイルを読むか、どのコマンドを実行するかは指示していません。テストの実行方法も、変更を最小限にするという規約も指示していません。これらは `CLAUDE.md` に書かれており、エージェントが起動時に読んでいます。

指示がこれだけで済む理由は、3章で扱います。ここでは、短い指示でも一巡が進むという事実だけを確認してください。

## コンテキストを集める局面では、現状を自分で調べます

エージェントは、まずファイルの一覧を取得し、テストを実行して失敗の内容を確かめました。

```
Bash: find . -type f -name "*.py" -not -path "./.git/*" | head -50 && python3 -m unittest 2>&1 | tail -40

./test_price.py
./price.py
---
.F
FAIL: test_thousands (test_price.TestFormatPrice.test_thousands)
AssertionError: '¥1234' != '¥1,234'
```

続いて、関係する2つのファイルを読みました。

```
Read: price.py
Read: test_price.py
```

この4つの操作は、人が指示していません。「失敗しているテストを直す」という目的から、エージェントが必要なものを判断しています。人がチャットに貼り付けていた情報を、エージェントが自分で集めた形になります。

## 動く局面では、ファイルを変更します

エージェントは `price.py` の1行を書き換えました。

```
Edit: price.py
    return f"¥{yen}"
  → return f"¥{yen:,}"
```

変更は1行です。テストファイルは変更していません。`CLAUDE.md` の「変更は最小限にする」「テストは変更しない」という2つの規約に従った結果です。

## 結果を確かめる局面では、変更を検証します

エージェントは、変更後にテストを実行し直しました。

```
Bash: python3 -m unittest

..
----------------------------------------------------------------------
Ran 2 tests in 0.000s

OK
```

この実行が「確かめる局面」です。変更したから終わりではなく、変更が意図どおりかをコマンドの実行で検証しています。ここで失敗していれば、エージェントはもう一度コンテキストを集める局面に戻ります。

## 完了すると、人に戻ります

エージェントは、何をどう変えたかを報告して停止しました。

```
テストが通りました。

price.py:2 の f"¥{yen}" を f"¥{yen:,}" に変更し、桁区切りカンマを
入れるようにしました。テストは 2 件とも成功しています。
```

このデモでは、指示から報告まで6回のやり取りで完了しました。

最後に残るのは、この変更を受け入れるかどうかの判断です。変更内容は `git diff` で確認できます。

```
$ git diff
 def format_price(yen):
-    return f"¥{yen}"
+    return f"¥{yen:,}"
```

## 人が関わったのは3か所です

この一巡で人がしたことは、指示を出すこと、途中で割り込むこと、結果を受け入れるかを判断することの3つです。

今回のデモでは、途中の割り込みは使いませんでした。使う場面と操作は、次の節で扱います。

残りはすべてエージェントが判断しています。どのファイルを読むか、どのコマンドを実行するか、どこを何行変えるか、変更が正しいかをどう確かめるか。これらは指示に含まれていません。

> [!NOTE]
> **出力の引用について** — 上に示した出力は、`price.py` の内容とテストの実行結果を実際に確認して引用したものです。画面上の進行状況の表示と装飾は省いています。実行環境は macOS 15、Claude Code v2.1.258 です。
