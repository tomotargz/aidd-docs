# コーディングエージェントを使った開発

## この章で身につくこと

コーディングエージェントの概要を知り、それを使った開発の流れを、教材を見ながら自分の環境で再現できるようになります。

## この章の主張

コーディングエージェントを使った開発は、チャット型の生成AIにコードを書かせることとは異なります。

違いは開発における情報収集・変更・動作確認のループを誰が回すかにあります。チャット型の生成AIを使うとき、ループを回すのは人です。コーディングエージェントを使うとき、ループはエージェント自身が回します。

ループの担い手が変わると、人の仕事内容も変化します。人はコードを書く代わりに、どこまで任せるかを決め、出てきた変更を受け入れるかを判断します。

## 節の構成

この章は3つの節に分かれます。

| 節 | タイトル | 受講者の作業 |
|---|---|---|
| 1 | チャットとエージェントは何が違うか | 読む |
| 2 | デモ: エージェントに小さな変更を任せる | 読む |
| 3 | 自分の環境で再現する | 手を動かす |

1節でエージェントの特徴をチャットとの比較を通じて学び、2節でエージェントを使った開発のデモを見て、3節で2節と同じ内容を自分のリポジトリで実行します。

3節に進む前に、コーディングエージェントの導入と認証を済ませ、`python3`が動くことを確かめてください。手順は3節の冒頭にあります。

## この章で扱わないこと

次の3つは、後の章に譲ります。

1. 指示の組み立て方（3章）
2. コーディングエージェントが失敗する条件（3章）
3. どこに人の確認を置くかの設計（4章）
