# 1章 コーディングエージェントを使った開発

## この章で身につくこと

コーディングエージェントを使った開発の流れを、教材を見ながら自分の環境で再現できるようになります。

再現できるとは、次の3つができる状態を指します。エージェントに小さな変更を任せられること、途中で止めて元に戻せること、実行を許可するかを自分で決められることです。

## この章の主張

コーディングエージェントを使った開発は、チャットにコードを書かせることとは別の作業です。

違いは出力の賢さではありません。情報を集め、ファイルを変え、結果を確かめるという一連の作業を、人が回すかエージェントが回すかにあります。この違いが、人の仕事をコードを書くことから判断することへ移します。

## 節の構成

3つの節に分かれます。所要時間は合わせて60分です。

| 節 | タイトル | 手を動かすか |
|---|---|---|
| 1 | チャットとエージェントは何が違うか | 読むだけ |
| 2 | デモ: エージェントに小さな変更を任せる | 読むだけ |
| 3 | 自分の環境で再現する | 手を動かす |

1節で違いを整理し、2節で実際の記録を追い、3節で自分の環境で同じことを行います。3節に進む前に、コーディングエージェントの導入と認証を済ませてください。手順は3節で案内します。

## この章で扱わないこと

ツールの製品比較と選定、コーディングエージェント自体の実装は扱いません。

指示の組み立て方、エージェントが失敗する条件、どこに人の確認を置くかの設計も、この章では扱いません。順に3章と4章で扱います。
