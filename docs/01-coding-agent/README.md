# コーディングエージェントを使った開発

## この章で身につくこと

コーディングエージェントを使った開発の流れを、教材を見ながら自分の環境で再現できるようになります。

再現できる状態とは、次の3つを満たすことです。

1. コーディングエージェントに小さな変更を任せられます。
2. コーディングエージェントが動いている途中で止め、加えられた変更を取り消せます。
3. コーディングエージェントがコマンドを実行してよいかを、自分で決められます。

2つ目と3つ目は、コーディングエージェントに備わっている操作です。Gitの操作ではありません。

## この章の主張

コーディングエージェントを使った開発は、チャット型の生成AIにコードを書かせることとは別の作業です。

違いは出力の賢さではなく、情報収集・変更・動作確認のループを誰が回すかにあります。チャット型の生成AIを使うとき、この3つを回すのは人です。コーディングエージェントは、この3つを自分で回します。

ループの担い手が移ると、人の仕事の中身も変わります。人はコードを書く代わりに、どこまで任せるかを決め、出てきた変更を受け入れるかを判断します。

## 節の構成

この章は3つの節に分かれます。

| 節 | タイトル | 受講者の作業 |
|---|---|---|
| 1 | チャットとエージェントは何が違うか | 読む |
| 2 | デモ: エージェントに小さな変更を任せる | 読む |
| 3 | 自分の環境で再現する | 手を動かす |

1節で違いを整理し、2節でデモの記録を追い、3節で2節と同じ変更を自分のリポジトリで実行します。3節で使う題材は2節に載せたものをそのまま使うため、2節を飛ばすと3節を始められません。

研修では、3つの節に合わせて60分を使います。3節で自分が手を動かす時間は、環境によって変わります。

## 3節を始める前に用意するもの

3節に進む前に、次の2つを済ませてください。

1. コーディングエージェントの導入と認証
2. `python3`が実行できること

導入と認証の手順は、3節の冒頭に案内があります。1節を読む前に着手しておくと、待たずに3節へ進めます。題材にするリポジトリは3節で作ります。中身は2節に載せた3つのファイルです。

## この章で扱わないこと

この章で扱わないことは、2種類に分かれます。教材全体で扱わないことと、後の章に譲ることです。

教材全体で扱わないのは、ツールどうしの比較と選定、およびコーディングエージェント自体の実装です。導入と認証の手順そのものも扱いません。3節で公式ドキュメントを案内します。

後の章に譲るのは、次の3つです。

1. 指示の組み立て方（3章）
2. コーディングエージェントが失敗する条件（3章）
3. どこに人の確認を置くかの設計（4章）
