# この教材の残りが何をするか

## はじめに

この節では、自分の現場のボトルネックがどこにあるかと、教材のどの章がそれに応えるかを対応づけます。

0章の目次には章の並びを載せました。この節が示すのは、ボトルネックの場所と章の対応です。

## コーディングを速くしても全体は変わらない

ボトルネックがコーディングの外にあるなら、コーディングを速くしても全体は変わりません。

1節では、エージェントが短くしたのが5つの工程のうち1つだけであることを見ました。2節では、AIが土台を増幅すること、増幅されるのが速さだけではないことを見ました。

増幅器はコーディングから出てくる量を大きくします。しかし、ボトルネックそのものは変わりません。その手前に変更が溜まるだけです。

変えるべきなのは、ボトルネックの側です。

## ボトルネックの場所と、応える章

ボトルネックがどこにあるかで、打つ手が変わります。

| ボトルネックの場所 | 起きていること | 応える章 |
|---|---|---|
| エージェントに渡すもの | 任せる単位が大きく、必要な情報が渡っていない | 3章 スモールバッチとコンテキスト |
| 人の確認 | レビューと承認で止まり、変更が溜まる | 4章 人による確認 |
| 変更を確かめる手段 | 戻せない、自動で確かめられない | 5章 バージョン管理とテスト自動化 |
| 統合と検査 | 人手で回しており、変更の量に追いつかない | 6章 継続的インテグレーション |
| 届けるまでの経路 | 統合できても、使える状態にするまでが遅い | 7章 継続的デリバリー |
| どこにあるか分からない | 手を打っても効果が見えない | 8章 制約を探す |
| 自分の権限の外にある | 変えるべき場所を一人では動かせない | 9章 組織に働きかける |

2行目から5行目までは、1節で並べた工程に対応します。1行目のエージェントに渡すものは工程ではなく、コーディングの入力にあたります。

## この節で確かめたこと

ボトルネックの場所によって、読むべき章が変わります。

自分の現場のボトルネックが分かっているなら、その行の章から読んでも構いません。分からないなら、8章が見つけ方を扱います。

3章から先は、ここで挙げた場所をひとつずつ扱っていきます。
