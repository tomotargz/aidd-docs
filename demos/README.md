# デモの題材

教材のデモで使うコードを置く。ディレクトリ名は `ch<NN>-<MM>-<スラッグ>` とし、原稿の frontmatter `demo_source` から参照する。

## ここにあるファイルが正である

原稿のコードブロックは、ここにあるファイルの引用として書く。**原稿だけを直すとデモが動かなくなる。** 変更するときはここのファイルを直し、原稿のコードブロックを合わせる。

`/verify-demo` は、このディレクトリをスクラッチ領域に複製して実行し、原稿のコードブロックと一致することを確認する。

## 注意

`ch01-02-shop/CLAUDE.md` は、デモの題材そのものである。**この教材リポジトリの規約ではない。** Claude Code がこのディレクトリで作業するときに読み込むことがあるため、内容を変更するときはデモの題材としての意味だけを考える。
